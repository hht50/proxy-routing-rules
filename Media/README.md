## 维护约定

1. 以后新增媒体规则优先按地区写入 `Media/<Region>/<Service>.list`。
2. 一个服务一个规则文件，规则文件只包含匹配条件，不写代理策略。
3. 旧路径暂不删除，保证 Surge / Mihomo / OpenClash 的现有 Raw 订阅继续有效。
4. 站点所属地区与代理出口分开记录；未确认的地区先放 Global。
5. 越南、台湾、香港、新加坡等地区按需要增建目录，不创建空文件夹。
